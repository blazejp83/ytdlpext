<task type="auto">
  <name>Task 1: Add format querying and folder opening</name>
  <files>companion/messaging/types.go, companion/main.go</files>
  <action>
  **New message types in types.go:**

  Add these constants and structs:
  - `TypeGetFormats = "getFormats"` — request from extension, Data contains `{ "url": "..." }`
  - `TypeFormats = "formats"` — response to extension with format list
  - `TypeOpenFolder = "openFolder"` — request from extension, Data contains `{ "path": "..." }`

  Add `GetFormatsRequest` struct: `URL string`

  Add `FormatsResponse` struct:
  - `Title string` — video/track title
  - `Duration float64` — duration in seconds
  - `Thumbnail string` — thumbnail URL
  - `VideoFormats []VideoFormat` — video formats sorted by resolution desc
  - `AudioFormats []AudioFormat` — audio-only formats sorted by bitrate desc

  Add `VideoFormat` struct: `FormatID string, Ext string, Resolution string, Width int, Height int, FPS float64, VCodec string, ACodec string, Filesize int64, TBR float64`

  Add `AudioFormat` struct: `FormatID string, Ext string, ABR float64, ACodec string, Filesize int64`

  Add `OpenFolderRequest` struct: `Path string`

  **Format querying in main.go:**

  Add handler for `TypeGetFormats`:
  1. Parse `GetFormatsRequest` from message Data
  2. Run yt-dlp with `--dump-json --no-download` on the URL using go-ytdlp (use `.DumpJSON()` or equivalent — check go-ytdlp API for getting JSON info without downloading)
  3. Parse stdout JSON output. The JSON contains a `formats` array where each format has: `format_id`, `ext`, `resolution`, `width`, `height`, `fps`, `vcodec`, `acodec`, `filesize` (nullable), `tbr`, `abr`, plus top-level `title`, `duration`, `thumbnail`
  4. Filter formats: video formats have `vcodec != "none"` and are NOT storyboard (skip formats where height <= 0 or format_note contains "storyboard"). Audio formats have `vcodec == "none"` and `acodec != "none"`.
  5. Sort: video by height desc then fps desc; audio by abr desc
  6. Deduplicate video formats: if multiple formats have same height+fps, keep the one with better codec (prefer h264/avc over vp9 for broader compatibility) or smaller filesize
  7. Send `TypeFormats` response with structured data
  8. On error, send `TypeError` with user-friendly message (e.g., "Could not fetch format info for this URL")

  **Folder opening in main.go:**

  Add handler for `TypeOpenFolder`:
  1. Parse `OpenFolderRequest` from message Data
  2. Expand tilde in path (reuse existing logic from download/manager.go)
  3. Open the directory using OS-appropriate command:
     - Linux: `xdg-open <dir>`
     - macOS: `open <dir>`
     - Windows: `explorer <dir>`
  4. Use `runtime.GOOS` to detect platform
  5. On error, send `TypeError` (non-critical, just log it)
  </action>
  <verify>
  Build succeeds: `cd companion && go build -o /dev/null .`
  Manually test format query: echo a getFormats message to stdin and verify JSON response structure
  </verify>
  <done>
  - getFormats handler returns structured video/audio format lists from yt-dlp
  - openFolder handler opens directory in OS file manager
  - All new types compile without errors
  </done>
</task>

<task type="auto">
  <name>Task 2: Extend download with format selection, audio extraction, and enhanced errors</name>
  <files>companion/messaging/types.go, companion/download/manager.go</files>
  <action>
  **Extend DownloadRequest in types.go:**

  Add fields to existing `DownloadRequest`:
  - `FormatID string` — specific format ID to download (empty = best quality, current behavior)
  - `AudioOnly bool` — extract audio only
  - `AudioFormat string` — target audio format: "mp3", "flac", "wav", "ogg" (only used when AudioOnly=true)
  - `EmbedMetadata bool` — embed metadata tags (artist, album, track)
  - `EmbedThumbnail bool` — embed cover art as thumbnail

  **Extend DownloadComplete in types.go:**

  Add field: `Directory string` — the directory containing the file (for openFolder support from extension)

  **Update StartDownload in download/manager.go:**

  Modify the go-ytdlp command construction based on new options:

  1. **Format selection:** If `req.FormatID != ""`:
     - Check if the format is video-only (this info should be passed or we handle it generically)
     - Use format `req.FormatID+bestaudio/req.FormatID` to auto-merge audio for video-only formats (DL-03 requirement). yt-dlp will skip the +bestaudio if the format already has audio.
     - Add `--merge-output-format mp4` to ensure merged output is mp4 (most compatible)
     - If FormatID is empty, keep current behavior: `bv*+ba/b` with `FormatSort("res,ext:mp4:m4a")`

  2. **Audio extraction:** If `req.AudioOnly`:
     - Use `.ExtractAudio()` flag
     - Set audio format via `.AudioFormat(req.AudioFormat)` (mp3, flac, wav, ogg)
     - For MP3: also set `.AudioQuality("0")` for best quality (VBR ~245kbps, close to 320k) or use `--audio-quality 320k` if go-ytdlp supports it. Check go-ytdlp API — if it has `.AudioQuality()`, use "320k" for MP3. For other formats, omit quality (lossless or native).
     - Do NOT set video format flags when audio-only

  3. **Metadata embedding:** If `req.EmbedMetadata`:
     - Add `--embed-metadata` flag (check go-ytdlp for `.EmbedMetadata()`)

  4. **Thumbnail embedding:** If `req.EmbedThumbnail`:
     - Add `--embed-thumbnail` flag (check go-ytdlp for `.EmbedThumbnail()`)

  5. **File naming:** Keep existing `%(title)s.%(ext)s` template (already satisfies DL-04)

  6. **Completion message:** Include `Directory` field in DownloadComplete so the extension can use it for "Open Folder" functionality. Extract directory from the resolved output path.

  **Enhanced error messages (DL-05):**

  Update the error mapping in friendlyError (or equivalent) to add:
  - ffmpeg missing during audio extraction: "ffmpeg is required for audio extraction. Install it: https://ffmpeg.org/download.html"
  - ffmpeg missing during muxing: "ffmpeg is required to merge video and audio. Install it: https://ffmpeg.org/download.html"
  - Requested format unavailable: "The selected format is no longer available. Try refreshing formats."
  - Network/connection errors: "Network error — check your internet connection"
  - Rate limiting: "Too many requests — wait a moment and try again"

  Keep existing error mappings (invalid URL, unsupported site, age-gated).
  </action>

  </verify>

  - Download supports format ID selection with auto audio merge
  - Audio-only extraction works with MP3/FLAC/WAV/Ogg
  - Metadata and thumbnail embedding flags applied when requested
  - DownloadComplete includes Directory for folder opening
  - Enhanced error messages cover ffmpeg, format, network failures
  </done>
