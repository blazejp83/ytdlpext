<task type="auto">
  <name>Task 1: Format picker UI and enhanced download flow</name>
  <files>extension/manifest.json, extension/popup.html, extension/popup.js, extension/popup.css, extension/service-worker.js</files>
  <action>
  **Manifest changes:**
  - Add `"notifications"` to permissions array (needed for PROG-02)

  **Service worker changes (service-worker.js):**

  Add message handlers:
  - `getFormats` from popup: forward to companion as `getFormats` message with `{ url }`, return response
  - `openFolder` from popup: forward to companion as `openFolder` message with `{ path }`
  - Handle `formats` response from companion: forward to requesting popup

  Add notification support:
  - On `complete` message from companion: create Chrome notification via `chrome.notifications.create()` with:
    - Title: "Download Complete"
    - Message: filename from complete data
    - IconUrl: extension icon (128px)
    - Type: "basic"
    - Store the download directory from complete message in a map keyed by notification ID
  - Add `chrome.notifications.onClicked` listener: when notification clicked, send `openFolder` to companion with the stored directory path, then clear the notification (PROG-03)

  Update `startDownload` handler:
  - Accept new fields from popup: `formatId`, `audioOnly`, `audioFormat`, `embedMetadata`, `embedThumbnail`
  - Pass these through to companion in the download message alongside existing `url` and `directory`

  **Popup HTML changes (popup.html):**

  Replace the single "Download Best Quality" button with a format selection UI:

  1. **Loading state:** When popup opens on supported page, show spinner with "Loading formats..." while fetching format list from companion
  2. **Format tabs:** Two tabs — "Video" and "Audio"
  3. **Video tab:**
     - "Best Quality" option at top (default, uses existing bv*+ba/b behavior)
     - List of available video formats showing: resolution (e.g., "1080p"), codec, file size (if available), fps
     - Each format is a selectable row/radio button
     - Download button at bottom
  4. **Audio tab:**
     - Format selector: MP3 (default), FLAC, WAV, Ogg — as a row of selectable chips/buttons
     - "Include metadata" checkbox (checked by default)
     - "Include cover art" checkbox (checked by default)
     - Download button at bottom
  5. **Keep existing states:** downloading progress, complete, error — these don't change

  **Popup JS changes (popup.js):**

  On popup open (when page is supported):
  1. Send `getFormats` to service worker with current page URL
  2. Show loading spinner
  3. On response: populate format lists, show format picker
  4. On error: show "Best Quality" button only (fallback to current behavior — don't block downloads if format query fails)

  Video download flow:
  1. User selects format (or "Best Quality" default)
  2. Clicks download
  3. Send `startDownload` with `{ url, title, formatId }` (formatId empty for best quality)

  Audio download flow:
  1. User switches to Audio tab
  2. Selects audio format (MP3/FLAC/WAV/Ogg)
  3. Toggles metadata and cover art checkboxes
  4. Clicks download
  5. Send `startDownload` with `{ url, title, audioOnly: true, audioFormat, embedMetadata, embedThumbnail }`

  **Popup CSS changes (popup.css):**

  Style the new format picker:
  - Tab bar: two tabs, active tab highlighted with accent color
  - Format list: scrollable container (max-height ~250px), each row with resolution/codec/size
  - Selected format row: highlighted background
  - Audio format chips: horizontal row of selectable pills
  - Checkboxes: styled consistently with existing UI
  - Loading spinner: centered, subtle animation
  - Keep popup width reasonable (350-400px)
  - Maintain existing dark/neutral color scheme from current popup.css
  </action>
