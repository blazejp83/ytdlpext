<task type="auto">
  <name>Task 2: Implement auto-close countdown logic</name>
  <files>extension/popup.js</files>
  <action>
Add a module-scoped variable `let autoCloseTimer = null;` near the other state variables (after `formatCache`).

Modify `showComplete(filename)`:
1. After showing the complete section and setting the filename, start a countdown:
   - Set a counter variable to 5
   - Update countdown-text to "Closing in 5s..."
   - Set `autoCloseTimer = setInterval(...)` that decrements the counter every 1000ms
   - Each tick: update countdown-text to "Closing in Xs..."
   - When counter reaches 0: clearInterval, call `window.close()`
2. Show the keep-open-btn and countdown-text (they should be visible by default in HTML, no hidden attr needed)

Add click handler for keep-open-btn:
- `clearInterval(autoCloseTimer); autoCloseTimer = null;`
- Hide countdown-text and keep-open-btn (set `.hidden = true` on both)
- This leaves the user on the complete screen with just the checkmark, filename, and "Download Another" button

Modify `downloadAnotherBtn` click handler to also clear the timer:
- Add `if (autoCloseTimer) { clearInterval(autoCloseTimer); autoCloseTimer = null; }` before calling loadFormats()

Modify `hideAll()` to also clear any running timer:
- Add `if (autoCloseTimer) { clearInterval(autoCloseTimer); autoCloseTimer = null; }` at the start of hideAll()
- This prevents stale timers if the user navigates away from the complete screen via any path (error, new download, etc.)

Do NOT add auto-close to error or cancelled states — only to the successful complete state.
  </action>

  </verify>
