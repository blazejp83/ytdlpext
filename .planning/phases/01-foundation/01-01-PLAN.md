<task type="auto">
  <name>Task 1: Build Go native messaging host</name>
  <files>companion/go.mod, companion/main.go, companion/messaging/io.go, companion/messaging/types.go, companion/host-manifest.json, companion/install.sh</files>
  <action>
  Initialize Go module in companion/ directory (module name: `ytdlext-companion`).

  **messaging/io.go** — Native messaging I/O:
  - `ReadMessage(r io.Reader) (*Message, error)`: Read 4-byte uint32 little-endian length from reader, then read exactly that many bytes, unmarshal JSON into Message struct. Return error on EOF or malformed input.
  - `WriteMessage(w io.Writer, msg *Message) error`: Marshal Message to JSON, write 4-byte uint32 LE length prefix to writer, then write JSON bytes. Flush if writer is buffered.
  - Use `encoding/binary.LittleEndian` for the length prefix. Chrome native messaging protocol requires this exact format.

  **messaging/types.go** — Message types and data structs:
  - `Message` struct: `Type string` + `Data json.RawMessage` (allows routing by type before unmarshaling data).
  - Constants: `TypePing = "ping"`, `TypePong = "pong"`, `TypeDownload = "download"`, `TypeProgress = "progress"`, `TypeComplete = "complete"`, `TypeError = "error"`.
  - `DownloadRequest` struct: `URL string`, `Directory string`.
  - `ProgressUpdate` struct: `DownloadID string`, `Percentage float64`, `Speed string`, `ETA string`, `Filename string`.
  - `DownloadComplete` struct: `DownloadID string`, `Filename string`, `Path string`.
  - `ErrorResponse` struct: `DownloadID string`, `Message string`.
  - Helper: `NewMessage(msgType string, data interface{}) (*Message, error)` — creates a Message with marshaled data.

  **main.go** — Entry point:
  - Main loop: repeatedly call `ReadMessage(os.Stdin)`, route by `msg.Type`.
  - Handle `ping` → respond with `pong` message (empty data).
  - Handle `download` → for now, respond with error "not implemented yet" (Plan 01-02 adds real implementation).
  - Unknown type → respond with error "unknown message type: X".
  - On ReadMessage EOF, exit cleanly (Chrome closed the connection).
  - All logging goes to stderr (stdout is reserved for native messaging protocol). Use `log.SetOutput(os.Stderr)`.

  **host-manifest.json** — Template for Chrome native messaging host registration:
  ```json
  {
    "name": "com.ytdlext.companion",
    "description": "ytdlext companion app for yt-dlp downloads",
    "path": "PLACEHOLDER_BINARY_PATH",
    "type": "stdio",
    "allowed_origins": ["chrome-extension://PLACEHOLDER_EXTENSION_ID/"]
  }
  ```

  **install.sh** — Installation script:
  - Accept extension ID as first argument ($1), error if not provided.
  - Build Go binary: `go build -o ytdlext-companion .` in companion/ directory.
  - Get absolute path to built binary.
  - Generate host manifest from template, replacing PLACEHOLDER_BINARY_PATH with absolute binary path and PLACEHOLDER_EXTENSION_ID with provided extension ID.
  - Detect Chrome variant: check for `~/.config/google-chrome/NativeMessagingHosts/` (Chrome) and `~/.config/chromium/NativeMessagingHosts/` (Chromium). Install to whichever exists, or both if both exist. Create directory if it doesn't exist.
  - Copy manifest as `com.ytdlext.companion.json` to the NativeMessagingHosts directory.
  - Print success message with instructions.
  - Make script executable (chmod +x in git).

  Add `lrstanley/go-ytdlp` dependency: `go get github.com/lrstanley/go-ytdlp@latest` (needed for Plan 01-02, but add now so go.mod is ready).
  </action>

<task type="auto">
  <name>Task 2: Build Chrome extension with site detection and popup shell</name>
  <files>extension/manifest.json, extension/service-worker.js, extension/popup.html, extension/popup.js, extension/popup.css, extension/content.js, extension/icons/icon16.png, extension/icons/icon48.png, extension/icons/icon128.png</files>
  <action>
  **manifest.json** — MV3 extension manifest:
  - manifest_version: 3, name: "ytdlext", version: "0.1.0"
  - permissions: ["nativeMessaging", "activeTab", "storage"]
  - background.service_worker: "service-worker.js"
  - action.default_popup: "popup.html"
  - action.default_icon: 16/48/128 PNGs from icons/
  - content_scripts: single entry matching all 5 supported domains:
    matches: ["*://*.youtube.com/*", "*://*.vimeo.com/*", "*://*.pornhub.com/*", "*://*.bandcamp.com/*", "*://*.soundcloud.com/*"]
    js: ["content.js"], run_at: "document_idle"

  **service-worker.js** — Background service worker:
  - Native host connection management:
    - `let port = null;` module-level variable.
    - `connectToHost()`: Call `chrome.runtime.connectNative("com.ytdlext.companion")`. Set up `port.onMessage` listener that routes responses to the appropriate popup/tab. Set up `port.onDisconnect` listener that logs `chrome.runtime.lastError`, sets `port = null`, and schedules reconnect after 1 second via `setTimeout(connectToHost, 1000)`. Limit reconnect attempts (max 5, reset on successful message exchange).
    - `sendToHost(message)`: If port is null, call connectToHost() first. Then `port.postMessage(message)`. Chrome serializes to JSON and adds length prefix automatically.
  - Heartbeat: When port is connected, `setInterval(() => sendToHost({type: "ping"}), 25000)` to keep service worker alive during long downloads.
  - Message listener from content scripts (`chrome.runtime.onMessage`):
    - On `{type: "pageDetected", url, title}`: Store URL/title keyed by sender.tab.id. Set badge: `chrome.action.setBadgeText({text: "DL", tabId: sender.tab.id})`, `chrome.action.setBadgeBackgroundColor({color: "#4A90D9", tabId: sender.tab.id})`.
  - Message listener from popup (also via `chrome.runtime.onMessage`):
    - On `{type: "getPageInfo"}`: Look up active tab info, respond with `{url, title, supported: true/false}`.
    - On `{type: "startDownload", url, directory}`: Forward to native host as `{type: "download", url, directory}`. (Actual handling in Plan 01-02.)
  - Forward native host messages (progress, complete, error) to popup via `chrome.runtime.sendMessage()`. Catch errors silently if popup is closed.
  - On service worker activate: call `connectToHost()`.
  - Tab update listener: `chrome.tabs.onUpdated` — clear stored page info when tab navigates away.

  **content.js** — Lightweight content script:
  - On load: `chrome.runtime.sendMessage({type: "pageDetected", url: location.href, title: document.title})`.
  - YouTube SPA handling: Listen for `yt-navigate-finish` event (YouTube-specific) and re-send pageDetected with new URL/title.
  - Generic SPA handling: Use `navigation` API if available (`navigation.addEventListener("navigateSuccess", ...)`), otherwise listen for `popstate` and `hashchange` events. On URL change, re-send pageDetected.

  **popup.html + popup.js + popup.css** — Popup UI shell:
  - HTML structure: Container div with: page-info section (title, URL), action section (download button), status section (hidden initially, for progress in Plan 02).
  - popup.js on DOMContentLoaded:
    1. Query active tab: `chrome.tabs.query({active: true, currentWindow: true})`.
    2. Send `{type: "getPageInfo"}` to service worker to get page state.
    3. If supported: show page title (truncated to ~60 chars), show "Download Best Quality" button (enabled).
    4. If not supported: show "Not a supported site" message, hide download button.
    5. Download button click handler: send `{type: "startDownload", url, directory}` to service worker. (Plan 02 will add progress handling.)
  - popup.css: Clean minimal styling. Fixed width ~350px. Use system font stack. Colors: #4A90D9 primary blue, #333 text, #f5f5f5 background. Download button: full-width, padded, blue background, white text, rounded corners. Hover/active states.

  **Icons** — Generate placeholder PNG icons:
  - Use Python3 to create solid-color PNGs if available: `python3 -c "..."` using struct module to write minimal valid PNGs (single color, no PIL dependency needed).
  - Alternatively use ImageMagick: `convert -size 16x16 xc:#4A90D9 icons/icon16.png`.
  - If neither available, create icons using a shell script that writes base64-decoded minimal PNG bytes.
  - Need 16x16, 48x48, 128x128 in #4A90D9 blue.
