  <action>
  **Download History:**

  In service-worker.js, in the `handleNativeMessage` function where `msg.type === "complete"` is handled:
  - After creating the notification, store a history record in chrome.storage.local:
    ```
    chrome.storage.local.get(["downloadHistory"], (result) => {
      const history = result.downloadHistory || [];
      history.unshift({
        url: currentDownload.url,
        title: currentDownload.title,
        filename: currentDownload.filename,
        directory: currentDownload.directory,
        timestamp: Date.now()
      });
      // Keep max 50 entries.
      if (history.length > 50) history.length = 50;
      chrome.storage.local.set({ downloadHistory: history });
    });
    ```

  In popup.html:
  - Add a small "History" link/button at the top-right of the popup header area (absolute positioned, font-size 12px, muted color, underline on hover).
  - Add a `#history-section` div (initially hidden) containing:
    - A "← Back" link to return to main view
    - A scrollable list container (max-height: 300px, overflow-y: auto)
    - Each history entry: title (truncated to 40 chars with ellipsis), filename, relative time (e.g. "2 min ago", "1 hour ago", "Yesterday"), and a small "Open Folder" button.
    - A "Clear History" button at the bottom (muted, small).

  In popup.js:
  - "History" link click: hide all other sections, show `#history-section`, load from `chrome.storage.local.get(["downloadHistory"])`.
  - Render each entry. Relative time helper: compute from `Date.now() - entry.timestamp`.
  - "Open Folder" button: send `{type: "openFolder", path: entry.directory}` via `chrome.runtime.sendMessage`.
  - "Clear History" button: set `downloadHistory: []` in storage, re-render empty state with "No downloads yet" message.
  - "← Back" link: hide history, show main view.

  In popup.css: style `.history-entry` (flex column, small gap, border-bottom separator, 8px padding), `.history-filename` (font-size 11px, muted), `.history-time` (font-size 10px, muted), `.history-empty` (centered, muted text).

  **Keyboard Shortcut:**

  In manifest.json, add:
  ```
  "commands": {
    "download-current": {
      "suggested_key": {
        "default": "Ctrl+Shift+D",
        "mac": "Command+Shift+D"
      },
      "description": "Download current page"
    }
  }
  ```

  In service-worker.js, add a command listener:
  ```
  chrome.commands.onCommand.addListener((command) => {
    if (command !== "download-current") return;
    chrome.tabs.query({ active: true, currentWindow: true }).then((tabs) => {
      if (tabs.length === 0) return;
      const tab = tabs[0];
      const info = pageInfo.get(tab.id);
      if (!info) return;
      if (!isSupportedUrl(info.url)) return;

      // Determine if audio-primary site.
      const hostname = new URL(info.url).hostname;
      const audioOnly = ["soundcloud.com", "bandcamp.com"].some(
        (h) => hostname === h || hostname.endsWith("." + h)
      );

      // Trigger quick download with defaults.
      chrome.storage.local.get(["downloadDirectory", "fileExists"], (result) => {
        const directory = result.downloadDirectory || "~/Downloads";
        const fileExists = result.fileExists || "overwrite";
        currentDownload = {
          id: null, url: info.url, title: info.title || "",
          status: "starting", percentage: 0, speed: "", eta: "", filename: ""
        };
        const downloadData = {
          url: info.url, directory, fileExists, audioOnly
        };
        if (audioOnly) downloadData.audioFormat = "mp3";
        sendToHost({ type: "download", data: downloadData });
      });
    });
  });
  ```

  Also update service-worker.js startDownload handler to pass through the new Phase 3 fields:
  - Add after existing format option passthrough: `if (message.sponsorBlockRemove) downloadData.sponsorBlockRemove = message.sponsorBlockRemove;`
  - Same for `subtitleLangs`, `embedSubs`, `useBrowserCookies`.
  </action>
